# Raw Data Folder

Place the experimental data here before running the analysis:

```text
data/raw/emulsion gel confocal.xlsx
data/raw/real confocal images of emulsion gels/
```

Expected Excel content:

- `image_file`
- `G'_1Hz`
- breaking stress column, such as `Breaking stress (Pa)` or `breaking stress`
- `protein type`
- `heat`
- `protein conc_percentage`
- `oil vol_percentage`
- `pH`
- `NaCl_mM`
- `CaCl2_mM`
- optional pixel calibration column used in the full workflow
