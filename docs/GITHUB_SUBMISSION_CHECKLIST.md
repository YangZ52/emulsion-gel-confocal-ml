# GitHub and Journal Submission Checklist

Before making the repository public, check:

- Remove private paths from scripts.
- Do not upload raw data unless journal policy, collaborator permissions, and data-sharing plans allow it.
- If raw data cannot be public, include a clear data availability statement.
- Include a small example dataset only if it is approved for sharing.
- Confirm that `README.md` describes how to place data and run the workflow.
- Confirm that all generated output folders are excluded from Git.
- Run the script once from a clean folder before submission.
- Record software versions in the manuscript or supplement.

Suggested manuscript data availability language:

> The analysis code and example metadata structure are available in the accompanying GitHub repository. Raw confocal images and rheological measurements are available from the corresponding author upon reasonable request, subject to data-sharing and file-size constraints.
